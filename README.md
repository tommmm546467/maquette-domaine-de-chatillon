# Maquette : Domaine de Châtillon

**Ceci n'est pas le site officiel du Domaine de Châtillon.**

C'est une **maquette de démonstration** réalisée par **OBT Agency** pour un rendez-vous commercial avec le
Domaine de Châtillon, domaine de gîtes de groupe à Châtillon-Saint-Jean (Drôme). Le domaine n'a pas encore
validé ce projet et n'en est pas propriétaire. Son site officiel reste domainedechatillon.fr.

- Les pages portent `noindex, nofollow` : elles ne doivent pas apparaître dans les moteurs de recherche ni
  concurrencer le site ou la fiche Google du domaine.
- Les textes, les photos, le logo, la vidéo et les affiches viennent du site public du domaine. Les photos des
  activités à voir sont des photos libres de Wikimedia Commons, créditées sur la page et dans les mentions légales.
- Les avis affichés sont des avis Google publics, recopiés mot pour mot.
- L'espace de gestion de l'agenda est une démonstration : ce qu'on y saisit reste dans le navigateur de la
  personne qui l'utilise, rien n'est publié pour les autres visiteurs.
- Les formulaires préparent un e-mail vers l'adresse publique du domaine : aucune donnée n'est collectée ici.

À la demande du domaine, ce dépôt et la page publiée seront retirés immédiatement.

Le contenu est généré depuis les sources du projet : ne rien corriger ici, tout serait écrasé au déploiement
suivant.
